# ORÍKÌ AI — Stage 2

Stage 2 establishes the ORÍKÌ application shell on top of the Stage 1 landing experience.

Included:
- Dashboard workspace
- Persistent application sidebar
- AI Library with local data
- Client-side AI search
- Purpose-driven discovery
- Favourites using localStorage
- Recent AI tracking using localStorage
- Compare view foundation
- Capability categories
- Workspace and About views
- Responsive desktop/tablet/mobile layout
- No backend, API keys, npm packages or external build dependencies

The Stage 1 landing page remains available through the Landing page control.
